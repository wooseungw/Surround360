SurroundBlip Model Learning Step Analysis

SurroundBlip 모델은 체계적인 학습을 위해 3단계의 전략을 사용합니다. 각 단계는 특정 능력을 모델에 주입하는 것을 목표로 하며, 서로 다른 Loss 함수를 조합하여 최적화를 수행합니다. 이 문서는 각 단계의 목표, 수식적 정의, 그리고 코드에 명시된 Loss 함수의 구현 흐름을 설명합니다.

Stage 1: Vision Pre-training

🎯 목표: 일관된 시각 표현 학습

Vision Encoder가 여러 장의 파노라마 이미지에 대해 일관성 있는 시각적 표현을 학습하도록 합니다. 겹치는 영역의 특징을 유사하게 만들어 시각적 연속성을 이해하는 것이 핵심입니다.

설명: VICReg Loss를 사용하여 인접 이미지의 겹치는 영역에서 추출된 패치 임베딩을 서로 유사하게 만듭니다. 이를 통해 모델은 시각적 특징의 불변성(Invariance)을 학습하게 됩니다.

인접 이미지에서 추출한 겹치는 영역의 임베딩 집합을 각각 $Z$와 $Z'$이라 할 때, VICReg 손실은 세 가지 항으로 구성됩니다.

$$ \mathcal{L}_{\text{VICReg}}(Z, Z') = \lambda \cdot s(Z, Z') + \mu \cdot [v(Z) + v(Z')] + \nu \cdot c(Z, Z') $$

⚙️ 데이터 순서도

Input: Surround Images
↓
Flatten Images
↓
Vision Encoder
↓
Reshape to Spatial
↓
Overlapping Patches
↓
VICReg Loss
↓
Overlap Loss

Stage 2: Q-Former Pre-training

🎯 목표: 시각-언어 정렬

Vision Encoder와 Language Model을 연결하는 Q-Former의 핵심 능력을 학습하는 과정입니다. 세 가지 손실 함수를 동시에 사용하여 이미지와 텍스트 간의 복합적인 관계를 학습합니다.

⚙️ 데이터 순서도

Input: Image & Text
↓
Vision Encoder
↓
Image Features
↓
(A) ITContrastive Loss
Image Features (Q-Former)
Text Features (Q-Former)
↓
Similarity Matrix
↓
ITC Loss
(B) ITMatching Loss
Image Query (Q-Former)
Pos/Neg Text Features
↓
Fusion (Q-Former)
↓
ITM Loss
(C) ITGenerative Loss
Visual Context (Q-Former)
↓
Projection Layer
↓
Generative Loss
↓
LM Loss
↓
Total Loss

설명: 이미지와 텍스트 간의 전역적 유사도를 학습합니다. 올바른 쌍은 가깝게, 틀린 쌍은 멀어지도록 임베딩 공간을 정렬합니다.

$$ \mathcal{L}_{\text{itc}} = \frac{1}{2} (\text{CE}(\text{sim}_{\text{i2t}}, y) + \text{CE}(\text{sim}_{\text{t2i}}, y)) $$

설명: 이미지-텍스트 쌍이 '일치'하는지 '불일치'하는지 예측하는 이진 분류 문제입니다. 세밀한 지역적 정렬을 유도합니다.

$$ \mathcal{L}_{\text{itm}} = \text{CE}(\text{itm_head}(h(v, t_{\text{pos/neg}})), y_{\text{pos/neg}}) $$

설명: 이미지를 문맥으로 삼아 관련된 텍스트를 생성하는 능력을 학습하여, 시각 정보를 이해하고 서술하는 능력을 기릅니다.

$$ \mathcal{L}_{\text{lm}} = - \sum_{k=1}^{L} \log P(w_k | w_{1}, \dots, w_{k-1}, v; \theta) $$

📊 최종 손실: total_loss = loss_itc + loss_itm + loss_lm

Stage 3: Instruction Fine-tuning

🎯 목표: 지시 따르기 학습

사전 학습된 모델을 특정 과제(예: VQA)에 맞게 미세 조정합니다. 사용자의 지시를 이해하고, 시각적 맥락에 맞는 정확한 답변을 생성하도록 학습합니다.

설명: 이 단계에서는 오직 생성 손실(LM Loss)만을 사용합니다. 사전 학습으로 얻은 정렬 능력을 바탕으로, 실제 과제 데이터에 대한 생성 능력을 극대화합니다.

$$ \mathcal{L}_{\text{finetune}} = - \sum_{k=1}^{L} \log P(w_k | w_{1}, \dots, w_{k-1}, v, \text{instruction}; \theta) $$

⚙️ 데이터 순서도

Input: Image, Instruction, Answer
↓
Visual Context Extraction
↓
Visual Prefix
↓
Generative Loss Calculation
↓
Finetune Loss
